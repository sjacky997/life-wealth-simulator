\# 人生財開始｜時間跳躍理財模擬器



香港投委會理財教育比賽參賽作品



\## 專案簡介



一個互動式 HTML 網站，透過「時間跳躍」模擬器讓大專生體驗 22 歲到 40 歲的理財決策，

建立對個人理財的初步認識，並引導參加後續工作坊。



\## 技術架構



\- 純前端：HTML + CSS + JavaScript

\- 響應式設計：手機 / 平板 / 桌面

\- 模組化架構：CSS 與 JS 分離

\## 使用說明



1\. 開啟 `index.html` 即可開始遊戲

2\. 玩家由 22 歲開始，經歷 5 個人生階段

3\. 每個階段有 3 張情境卡，共 15 個決策

4\. 完成後生成個人理財人格與結局卡片

5\. 結尾引導報名工作坊
